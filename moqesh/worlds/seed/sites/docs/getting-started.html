Getting started

Request access through the internal portal, then authenticate against the gateway to obtain a short-lived token. Tokens are scoped per service and expire after 60 minutes.

Local setup

git clone git@git.internal:platform/console.git
cd console
make bootstrap
make run        # serves on :8080

API overview

Service health is exposed as a small JSON document; the status page publishes a machine-readable summary. Example:

curl -s https://console.internal/api/health.json
curl -s https://console.internal/status/api/summary.json

Authenticated service endpoints live behind the gateway and require a short-lived bearer token (see above).
