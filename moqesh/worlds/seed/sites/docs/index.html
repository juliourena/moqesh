Introduction

Internal engineering documentation for the Harborline platform.

This handbook covers how our services are built, deployed and operated. It is intended for engineers on the platform and on-call rotations. For access requests, use the internal portal.

Platform at a glance

The platform is a set of services behind the auth-gateway, deployed to Kubernetes via the CI pipeline. Configuration is managed declaratively; production changes go through review.

Conventions

Services expose a /health endpoint and emit structured logs. Secrets are managed by the secrets store and never committed. See Getting started.
